# ⚾ 숫자야구 · 🔍 틀린그림찾기

방 코드 하나로 친구와 1:1 온라인 대전을 하는 미니 게임 모음.
숫자야구는 혼자일 땐 AI와, 틀린그림찾기는 혼자일 땐 기록에 도전합니다.
브라우저만 있으면 되고, 설치할 앱도 회원가입도 없습니다.

![홈 화면](docs/home.png)

## 무엇이 되나요

- **온라인 1:1 대전** — 방을 만들면 4글자 코드가 나옵니다. 친구에게 코드나 초대 링크를 보내면 끝. 코드 하나로 두 게임 모두 참가할 수 있습니다.
- **숫자야구** — 3~6자리, 한 턴 제한시간(30 / 60 / 120초 / 무제한). 혼자일 땐 AI 연습(쉬움 / 보통 / 어려움).
- **틀린그림찾기** — 그림은 매판 코드로 새로 만들어집니다(들판 / 바닷속 / 밤거리). 둘이 같은 그림을 보고 먼저 찾는 사람이 임자. 혼자일 땐 제한시간 안에 모두 찾기 + 최고 기록.
- **끊겨도 안 끝남** — 새로고침하거나 잠깐 연결이 끊겨도 60초 안에 돌아오면 원래 자리에서 이어서 합니다.
- **재대결** — 둘 다 누르면 바로 다음 판.
- **채팅** — 대전 중 간단한 메시지.
- 모바일 우선 레이아웃, 다크 모드 자동 지원.

## 게임 규칙

### 숫자야구

1. 둘 다 **서로 다른 숫자**로 된 비밀번호를 정합니다. (3자리라면 `427` 처럼. `0`으로 시작해도 됩니다)
2. 번갈아 가며 상대의 숫자를 추측합니다.
   - **스트라이크(S)** — 숫자와 자리가 모두 맞음
   - **볼(B)** — 숫자는 있는데 자리가 다름
   - **아웃** — 하나도 없음
3. 먼저 전부 스트라이크를 만들면 승리.
4. 단, **선공이 맞히면 후공에게 마지막 공격권**이 한 번 주어집니다. 후공도 맞히면 **무승부** — 선공 이점을 없애기 위한 규칙입니다.
5. 제한시간을 넘기면 그 턴은 날아가고, **연속 3번** 놓치면 기권 처리됩니다.
6. 비밀번호를 정하는 시간(90초)을 넘기면 무작위 숫자가 자동으로 배정됩니다.

### 틀린그림찾기

1. 두 그림에서 **서로 다른 곳**을 찾아 누릅니다. 어느 쪽 그림을 눌러도 됩니다.
2. 온라인 대전은 둘이 **같은 그림**을 동시에 봅니다. 먼저 누른 사람이 그 자리를 가져갑니다.
3. 다 찾거나 **남은 개수로 역전이 불가능**해지면 바로 끝. 시간이 끝나면 더 많이 찾은 사람이 이기고, 같으면 무승부입니다.
4. 틀린 곳을 누르면 **1.5초** 동안 누를 수 없습니다. (마구 누르기 방지)
5. 혼자 하기는 제한시간 안에 모두 찾으면 성공. 힌트를 쓰면 **10초**가 줄어듭니다.

| 난이도 | 틀린 곳 | 제한시간 | 차이 종류 |
| --- | --- | --- | --- |
| 쉬움 | 5곳 | 90초 | 사라짐 · 색 · 크기 |
| 보통 | 7곳 | 120초 | + 모양(창문·줄무늬·꽃잎 수…) · 좌우 반전 |
| 어려움 | 9곳 | 150초 | + 부분 색(나무 줄기·집 지붕…), 크기 변화가 더 작음 |

## 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
```

개발 중에는 `npm run dev` (파일이 바뀌면 자동 재시작).

같은 와이파이의 휴대폰에서 테스트하려면 PC의 내부 IP로 접속하면 됩니다 (`http://192.168.x.x:3000`).

## 배포하기

WebSocket을 쓰기 때문에 **상시 실행되는 서버**가 필요합니다. 정적 호스팅(GitHub Pages 등)만으로는 온라인 대전이 동작하지 않습니다. (AI 연습 모드는 정적 파일만으로도 동작합니다.)

### Render

저장소를 연결하면 `render.yaml` 설정이 그대로 적용됩니다. 수동으로 만든다면:

| 항목 | 값 |
| --- | --- |
| Environment | Node |
| Build Command | `npm ci` |
| Start Command | `npm start` |
| Health Check Path | `/healthz` |

무료 플랜은 일정 시간 요청이 없으면 잠들기 때문에, 첫 접속이 느릴 수 있습니다.

### Railway

New Project → Deploy from GitHub repo 로 이 저장소를 고르면 자동으로 감지합니다.
포트는 `PORT` 환경변수로 들어오며 서버가 알아서 사용합니다. 따로 설정할 것은 없습니다.

### 환경변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `HOST` | `0.0.0.0` | 바인딩 주소 |

## 프로젝트 구조

```
shared/         서버와 브라우저가 함께 쓰는 순수 로직 (의존성 없음)
  baseball.js     숫자 검증, 스트라이크/볼 판정, 후보 생성
  engine.js       숫자야구 상태머신 — 턴, 제한시간, 승패 판정
  spotdiff.js     틀린그림찾기 그림 생성기 — 시드로 장면을 만들고 차이를 심고 SVG 로 그린다
  spotengine.js   틀린그림찾기 상태머신 — 카운트다운, 누르기 판정, 잠금, 승패
server/
  index.js        HTTP(정적 파일) + WebSocket 서버
  rooms.js        방 코드 발급, 자리 배정, 재접속 유예, 브로드캐스트
  games.js        방이 돌릴 수 있는 게임 목록 (규칙 함수 묶음)
public/
  index.html      화면 뼈대
  css/style.css
  js/app.js       화면 그리기와 입력 처리, 홈 탭
  js/spotui.js    틀린그림찾기 화면 — 두 그림 그리기, 누르기, 표시
  js/net.js       온라인 엔진 (WebSocket, 자동 재접속)
  js/local.js     AI 연습 엔진 (숫자야구 상태머신을 브라우저에서 구동)
  js/spotsolo.js  혼자 하기 엔진 (틀린그림찾기 상태머신을 브라우저에서 구동)
  js/ai.js        AI 상대 — 난이도별 추론
test/           node:test 기반 단위 + 통합 테스트
```

핵심은 **규칙이 `shared/` 한 곳에만 있다**는 점입니다.
온라인 모드는 서버가 상태머신을 돌리고, 로컬 모드(AI 연습·혼자 하기)는 브라우저가 똑같은 것을 돌립니다.
두 엔진이 같은 모양의 상태를 내보내기 때문에 화면 코드는 둘을 구분하지 않습니다.
방(`server/rooms.js`)은 어떤 게임인지 모르고, `server/games.js` 가 골라 준 규칙 함수만 부릅니다.

### 틀린그림은 어떻게 만드나요

그림 파일이 없습니다. `shared/spotdiff.js` 가 시드 하나로 장면을 만듭니다 —
테마(들판 / 바닷속 / 밤거리)를 고르고, 물건(나무·집·물고기·건물·자동차…)을 겹치지 않게 흩뿌린 뒤,
그중 몇 개를 골라 **사라짐 / 색 / 크기 / 모양 / 좌우 반전 / 부분 색** 중 하나로 바꿉니다.
차이의 판정 원은 서로 겹치지 않고, 앞에 있는 물건에 가려지지 않는 곳만 고릅니다.
같은 시드면 언제나 같은 그림이 나오므로 테스트하기 쉽습니다.

정답 좌표는 서버만 갖고 있고 `view` 에는 두 그림의 물건 목록과 **찾은 곳**만 내려갑니다.
(두 목록을 비교하면 차이를 알아낼 수는 있습니다 — 친구끼리 하는 게임이라 그 정도는 막지 않습니다.)

### AI는 어떻게 두나요

지금까지 받은 단서와 모순되지 않는 후보를 추려 그중 하나를 고릅니다.
난이도는 **단서를 얼마나 기억하느냐**로 조절합니다 — 쉬움일수록 과거 단서를 자주 잊고(`memory`), 가끔은 아무 숫자나 던집니다(`noise`). 값은 `public/js/ai.js` 의 `PROFILES` 에 모여 있습니다.

| 난이도 | 단서 기억률 | 무작위 확률 |
| --- | --- | --- |
| 쉬움 | 45% | 30% |
| 보통 | 80% | 10% |
| 어려움 | 100% | 0% |

## WebSocket 프로토콜

`/ws` 로 접속해 JSON 메시지를 주고받습니다.

**클라이언트 → 서버**

| 메시지 | 내용 |
| --- | --- |
| `{t:'create', game, name, digits, turnSeconds, level}` | 방 만들기 — `game` 은 `baseball`(기본) 또는 `spot`. 숫자야구는 `digits`·`turnSeconds`, 틀린그림찾기는 `level`(`easy`/`normal`/`hard`) |
| `{t:'join', code, name}` | 방 참가 |
| `{t:'rejoin', code, token}` | 끊긴 자리로 복귀 |
| `{t:'secret', value}` | 내 비밀번호 확정 |
| `{t:'guess', value}` | 공격 (숫자야구) |
| `{t:'tap', x, y}` | 그림 누르기 (틀린그림찾기, 400×300 장면 좌표) |
| `{t:'chat', text}` | 채팅 |
| `{t:'rematch'}` / `{t:'surrender'}` / `{t:'leave'}` | 재대결 / 기권 / 나가기 |

**서버 → 클라이언트**

| 메시지 | 내용 |
| --- | --- |
| `{t:'joined', code, you, token}` | 자리 배정 + 재접속 토큰 |
| `{t:'state', game, code, view, chat, grace}` | 전체 상태 (바뀔 때마다) |
| `{t:'error', code, message}` | 거절 사유 |

`view` 에는 **상대의 비밀번호(숫자야구)나 정답 위치(틀린그림찾기)가 들어 있지 않습니다.** 게임이 끝난 뒤에만 공개됩니다.

## 테스트

```bash
npm test
```

- `test/baseball.test.js` — 판정 규칙
- `test/engine.test.js` — 숫자야구 상태머신 (마지막 공격권, 무승부, 시간 초과, 기권, 재대결, 정보 은닉)
- `test/spotdiff.test.js` — 그림 생성 (같은 시드 → 같은 그림, 난이도별 개수, 판정 원 비겹침, 그리기)
- `test/spotengine.test.js` — 틀린그림찾기 상태머신 (판정, 잠금, 조기 종료, 시간 종료 비교, 힌트, 재대결, 정보 은닉)
- `test/server.test.js` — 실제 서버를 띄워 소켓 두 개로 두 게임을 끝까지 진행, 재접속과 에러 처리까지
